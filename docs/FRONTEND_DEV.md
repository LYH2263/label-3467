# 前端开发说明

## 前端完成了什么
- 构建 `Psyche Game` 主站首页，包含游戏广场、攻略流、热文榜与筛选区。
- 实现用户认证页面（登录/注册/重置密码）与个人中心。
- 实现攻略发布/编辑、详情查看、评论互动、点赞与分享统计展示。
- 实现“创作数据中心”：展示作者文章的浏览量、点赞量、评论量、热度排行。
- 实现“导出分析报表”前端下载流程（对接后端 POI 导出接口）。

## UI/UX 设计策略
- 采用“简洁留白 + 动态背景 + 玻璃卡片”组合，保持整洁且具科技感。
- 顶部导航常驻，关键操作路径 1-2 次点击可达。
- 重点场景加入交互反馈：骨架屏、空态、按钮 loading、错误消息提示。
- 移动端采用断点重排（网格转单列），避免横向滚动和内容重叠。

## 前端技术选型
- Vue 3 + Composition API：组件化与状态组织清晰。
- Element Plus：快速交付高一致性组件与表单能力。
- Pinia：认证态、主题态管理。
- Vue Router：受控路由与权限拦截。
- Axios：统一请求拦截、错误处理。

## 关键目录
- `frontend/src/layouts/MainLayout.vue`：导航布局与主题切换。
- `frontend/src/pages/HomePage.vue`：游戏广场 + 攻略列表 + 排行榜。
- `frontend/src/pages/MyArticlesPage.vue`：作者数据中心与报表导出入口。
- `frontend/src/styles/theme.css`：全局视觉系统与动画定义。
