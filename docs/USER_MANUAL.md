# 用户手册

## 1. 浏览游戏与攻略
1. 打开首页“游戏广场”查看热门游戏入口。
2. 点击“立即开玩”可跳转至外部小游戏页面。
3. 下滑到攻略区，可按关键词、分区、日期筛选文章。

## 2. 发布攻略
1. 登录后点击“发布文章”。
2. 填写标题、分类、标签、摘要、正文内容。
3. 可上传封面与正文图片。
4. 点击“发布攻略”或“保存草稿”。

## 3. 查看作者数据
1. 进入“创作数据中心”。
2. 查看总浏览量、总点赞量、总评论数、已发布数量。
3. 查看文章热度排行并可跳转详情。
4. 点击“导出分析报表”下载 Excel。

## 4. 互动功能
- 文章详情页支持评论、回复、点赞、分享。
- 作者可在“历史记录”查看版本变更。
